SnckFRP

A simple project home for the FRP source distribution, build checks, and Linux installation.

Install on Linux View repository

One-command installer

On Ubuntu or Debian, the installer can add the required build packages, build both binaries, and install them.

curl -fsSL https://raw.githubusercontent.com/SnckBoy/snckfrp/main/install.sh | bash

Review the installer before running it. It installs the binaries only; it does not create services, open ports, or change firewall rules.
