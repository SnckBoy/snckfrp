SnckFRP

Project home, build status, and installation guide.

Install on Linux

Requires Git, Make, and Go 1.26 or newer. The installer builds and installs the client and server binaries; it does not start services or change firewall settings.

curl -fsSL https://raw.githubusercontent.com/SnckBoy/snckfrp/main/install.sh | bash

About the web interface

This GitHub Pages site is static documentation. It cannot run the FRP server or client. The FRP web dashboards run with their corresponding server/client processes on a machine you administer; they are not hosted by GitHub Pages.

Keep administrative dashboards private and protected. Do not expose them directly to the public internet.

SnckFRP is a source distribution of FRP. Preserve upstream license notices.
